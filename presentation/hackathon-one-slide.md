# Hackathon — Software Mention Extraction

<div class="meta">

**Séminaire Santé Numérique 2026** · Campus Biaggi, Marseille · 14–15 October 2026
Luca Foppiano (ScienciaLAB, Inria) · Clémence Sebe (LISN, Université Paris-Saclay)

</div>

<div class="points">

- 🎯 **Goal:** extract and analyse the software mentioned in **PEPR Santé Numérique** publications: which software is *used* or *created*, and which methods work for finding it.
- 🧰 **Ready to use:** the PEPR HAL corpus processed with GROBID (🤗 Hugging Face), annotated corpora (SoftCite, SoMeSci, SoFAIR, BioToFlow) and models (Softcite and Baguette hosted, CoPaLink).
